## Proposed Action Plan (Priority Order)

### Phase A: Fix Critical Issues (1-2 hours)

1. **Update all docs: Gemini → Groq** across README.md, ARCHITECTURE.md, docs/DEMO_SCRIPT.md, docs/API.md
2. **Fix .env security**: `git rm --cached .env`, create `.env.example` with placeholders
3. **Add LICENSE file** (MIT)
4. **Fix `/api/sessions` auth bypass**: Remove redirect, add proper route that checks auth
5. **Persist session score/recommendation**: After report generation, update session record
6. **Mark session completed**: Add `POST /api/session/{id}/complete` endpoint or auto-complete on last answer

### Phase B: Polish & UX (2-3 hours)

7. **Add 404 page** with navigation back to dashboard
8. **Wire up unused prompts**: Connect `report_generator` and `learning_path` to services
9. **Remove dead code**: `ScoreBreakdown.tsx`, `interviewStore.ts` (or consolidate), unused schema classes
10. **Add error boundaries** to main routes
11. **Improve PDF**: Add scores summary header, page numbers

### Phase C: Presentation Polish (1-2 hours)

12. **Mobile hamburger menu** (if time allows -- most hackathon demos are on desktop)
13. **Loading skeletons** for dashboard and results pages
14. **Clean up orphan files** (root package-lock.json, unused CVA dependency)
